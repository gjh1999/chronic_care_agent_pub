# 手动启动命令(替代一键脚本)

> 适用场景:双击 `start_all.bat` 闪退、脚本异常,或想看清每一步日志时。
> 说明:每个服务会占用当前窗口持续运行,所以**每启动一个服务就新开一个 cmd 窗口**(共 4 个窗口)。

## 开窗口

按 `Win + R`,输入 `cmd`,回车。需要几个窗口就重复几次。

---

## 窗口 1:RAG 检索服务(端口 8010)

```bat
cd /d C:\Users\gjh\PycharmProjects\RAG
.venv\Scripts\python.exe -m uvicorn service_app:app --host 127.0.0.1 --port 8010
```

看到 `Uvicorn running on http://127.0.0.1:8010` 即成功。

## 窗口 2:意图识别服务(端口 8020,7B 模型加载需 5~10 分钟)

```bat
cd /d C:\Users\gjh\PycharmProjects\Medical_Lora
.venv\Scripts\python.exe -m uvicorn service_app:app --host 127.0.0.1 --port 8020
```

看到 `Uvicorn running on http://127.0.0.1:8020` 即成功。

## 窗口 3:本项目后端(端口 8000)

```bat
cd /d C:\Users\gjh\PycharmProjects\chronic_care_agent_2
.venv\Scripts\python.exe scripts\init_db.py
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

- `init_db.py` 只在**第一次**启动(或数据库结构升级后)需要跑,之后可跳过;
- 看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。

## 窗口 4:前端 H5(端口 5173)

```bat
cd /d C:\Users\gjh\PycharmProjects\chronic_care_agent_2\miniprogram
npm run dev:h5
```

看到 `Local: http://localhost:5173/` 即成功(首次运行前需先执行一次 `npm install`,已装过则不用)。

登录:网页登录页输入不同昵称即可模拟不同测试账号。

## 停止

最简单:把 4 个 cmd 窗口直接关掉。

命令行方式(按端口杀进程,端口号换成要停的服务):

```bat
netstat -ano | findstr :8000
taskkill /F /PID 上面查到的PID
```

常用端口:8010(RAG)、8020(意图)、8000(后端)、5173(前端)。

## 常见问题

- **窗口 2 启动报 GPU 相关错误**:关掉窗口重试一次即可(模型加载时偶发显存分配冲突)。
- **前端提示端口被占用**:旧进程没关干净,用上面的 `netstat` + `taskkill` 杀掉 5173 上的进程再启动。
- **`python` 不是内部或外部命令**:必须用 `.venv\Scripts\python.exe`(每个项目的虚拟环境路径已写在上面的命令里)。
